# 审查决策记录（Audit Decision Log）

> 关联：A–H 八维审查（2026-09）· docs/audit-report.md · 18-视觉规范审计报告.md
> 原则：凡涉及"多来源冲突/品牌视觉"的结论，在此记录裁决与理由，保证可回溯、可回滚。

## D1 · 六语义色唯一源（P0 G-P0-1 裁决）
- **冲突**：`goodmom-ui/src/tokens/status.ts` 用深色语义集（positive `#2f8f76` / info `#4a76d0` / attention `#b9771c` / risk `#d35466` / neutral `#757e8e` / special `#7a5ce0`）；而 14 · 4.4.5 原表把六语义直接指向 `-500` 鲜艳档（`--mmh-mint-500` `#6FC9B4` 等）。
- **裁决（以 alias 层为唯一落地源）**：状态「文字/色点/标签」一律使用**语义 alias 深色**（= 代码现状 `#2f8f76` 系，浅底对比度达标）；`-500/-300` 鲜艳档仅作**填充/色块/图表强调**。理由：① alias 深色在浅底玻璃上 ≥4.5:1，适合医疗信息可读；② 18 报告与代码/audit 已按此归一，回改会大规模破坏现状；③ 14 表改为「alias + 填充档」双层表述，消除单一"Token=值"的歧义。
- **落地**：14 · 4.4.5 表 + 02 · 2.1.5 用途分层说明 + `theme.css` 新增 `--lg-sem-*` 变量；07/15 语义词不改。

## D2 · 白字/小字对比度口径（P0 D-P0① 部分裁决）
- 文档层面废弃两处**非 WCAG 豁免口径**（"≥13px/600"、"≥12px 辅助"）：改为 AA 真口径——小字号白字只落在 ≥4.5:1 深实底；品牌亮渐变仅承载 ≥24px 常规/≥18.66px 加粗展示字。
- **新增高对比主行动 token** `--mmh-grad-action-hc`（`#C94A77→#B23A63`）与 `.gm-btn-hc` 形态，供"小而可读的实底 CTA"使用。
- **遗留（需设计负责人确认，未擅自全站换色）**：存量演示页/品牌渐变上的小号白字——是否整体切深渐变或改深字，见路线图 L 档。

## D3 · 其它裁决/说明
- GmTag 与 GmStatusTag：**不合并**——前者为自包含轻量（无 Arco 依赖），后者为 Arco Tag 形态；同属"状态标签"语义但服务于不同引擎上下文。持续共享 `SEMANTIC_COLOR` 单一映射源，避免色值漂移（代码头注释已标注）。
- 文档计数口径：00 目录“94 组件 = 规范全量”，组件库 README 已标“已封装子集 9/94”。
