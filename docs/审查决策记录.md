## D1 · 六语义色唯一源（P0 G-P0-1 裁决）
- **冲突**：`goodmom-ui/src/tokens/status.ts` 用深色语义集（positive `#2f8f76` / info `#4a76d0` / attention `#b9771c` / risk `#d35466` / neutral `#757e8e` / special `#7a5ce0`）；而 14 · 4.4.5 原表把六语义直接指向 `-500` 鲜艳档（`--mmh-mint-500` `#6FC9B4` 等）。
- **裁决（以 alias 层为唯一落地源）**：状态「文字/色点/标签」一律使用**语义 alias 深色**（= 代码现状 `#2f8f76` 系，浅底对比度达标）；`-500/-300` 鲜艳档仅作**填充/色块/图表强调**。理由：① alias 深色在浅底玻璃上 ≥4.5:1，适合医疗信息可读；② 18 报告与代码/audit 已按此归一，回改会大规模破坏现状；③ 14 表改为「alias + 填充档」双层表述，消除单一"Token=值"的歧义。
- **落地**：14 · 4.4.5 表 + 02 · 2.1.5 用途分层说明 + `theme.css` 新增 `--lg-sem-*` 变量；07/15 语义词不改。

## D2 · 白字/小字对比度口径（P0 D-P0① 部分裁决）
- 文档层面废弃两处**非 WCAG 豁免口径**（"≥13px/600"、"≥12px 辅助"）：改为 AA 真口径——小字号白字只落在 ≥4.5:1 深实底；品牌亮渐变仅承载 ≥24px 常规/≥18.66px 加粗展示字。
- **新增高对比主行动 token** `--mmh-grad-action-hc`（`#C94A77→#B23A63`）与 `.gm-btn-hc` 形态，供"小而可读的实底 CTA"使用。
- **遗留（需设计负责人确认，未擅自全站换色）**：存量演示页/品牌渐变上的小号白字——是否整体切深渐变或改深字，见路线图 L 档。

## D4 · A1 页面暖色/引擎展示色收口（2026-09）
- 问题：site/preview 静态页样式含大量暖底别名（#FDF2EE/#F6E2DB/#F0D4CF…）与引擎 ramp/渐变样例色（#72DDE5/#A98BFF/#7D66F2…），audit 整页扫描产生 color-html WARN；且整页扫描会把文档正文里的 token 表 hex 误报为样式色。
- 处理：① color-html 检查限定在 CSS 上下文（`<style>` 与 `style=""`），正文/表格里的文档化 hex 不再误报；② 新增审计档 `PAGE_ALIAS`（页面档别名/引擎展示色，仅静态页适用，代码层仍受 `ALLOWED` 严格约束）；③ 决策记录留档，后续页面新增同档色须并入 PAGE_ALIAS 并登记理由。
- 结果：`audit.py` color-html 输出 OK（无 WARN），仍 PASS。

## D5 · 白字实底达标档落地（2026-09）
- 实测（WCAG 2.x，白字 vs 底色）：alias 深色集仅适合「深字浅底」文本；白字需要更深的 **solid 档**。顶部 40% 白色高光会进一步稀释（alpha.40 时全部跌破 4.5），故状态 chip 移除高光层。
- 新增 token：`--mmh-solid-positive #1e6b52(6.40)` / `attention #9a5a0e(5.46)` / `danger #b04052(5.67)` / `info #385cb3(6.27)` / `special #6242b8(7.02)`；`--mmh-grad-action-hc` 端点更新为 `#B23A63→#9E3054`（白字 5.71 / 6.99）。
- 已落地：preview/index.html `.bx-solid.st-success/warning/danger` 改为深实底 + 去高光（白字 ≥5.4:1）。
- 仍待设计负责人：`.bx-primary/.bx-secondary`（品牌亮渐变 + 白字小按钮）与品牌主 CTA 的整体换色——已提供 `.gm-btn-hc`/`--mmh-grad-action-hc` 落地路径。
