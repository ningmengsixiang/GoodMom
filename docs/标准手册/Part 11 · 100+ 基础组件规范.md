## 3 条款
- CP-11-01 应：每个组件状态全覆盖——默认/hover(触屏 press)/focus-visible/disabled(给理由)/loading(不换内容)/error(三通道)/empty/(可编辑加 read-only)（07.8 矩阵）。
- CP-11-02 应：props 克制且可组合；同义场景复用同组件（状态标签 GmStatusTag/GmTag 共享 SEMANTIC_COLOR，D3 不合并但同源）。
- CP-11-03 应：主题与局部定制经 Token/var（组件内 0 魔法色）；不可改则需登记豁免（决策记录）。
- CP-11-04 应：封装子集 12 模块（GmButton/StatusTag/Tag/Card/Avatar/Progress/Steps/RiskPicker/ClientCard/Empty/Spin/Skeleton）；未封装组件先用 Arco 原生＋gm-* 主题类实现并按 00 登记回填。
- CP-11-05 应：引擎基底 Arco（React），Semi 对齐矩阵见 08；自包含轻量适配仅限 GmTag/GmSteps 类。
- CP-11-06 应：组件新增完成 index.ts 导出 + README + coverage 计数 + `npm run typecheck`（CI）。
