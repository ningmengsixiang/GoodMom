## 3 条款
- CP-11-01 应：每个组件状态全覆盖——默认/hover(触屏 press)/focus-visible/disabled(给理由)/loading(不换内容)/error(三通道)/empty/(可编辑加 read-only)（07.8 矩阵）。
- CP-11-02 应：props 克制且可组合；同义场景复用同组件（状态标签 GmStatusTag/GmTag 共享 SEMANTIC_COLOR，D3 不合并但同源）。
- CP-11-03 应：主题与局部定制经 Token/var（组件内 0 魔法色）；不可改则需登记豁免（决策记录）。
- CP-11-04 应：封装子集 16 模块（GmButton/StatusTag/Tag/Card/Avatar/Progress/Steps/RiskPicker/ClientCard/Empty/Spin/Skeleton + GmLink/GmCascader/GmResponsiveView/GmVirtualList）；未封装组件先用 Arco 原生＋gm-* 主题类实现并按 00 登记回填；新增封装必须在两包 `index.ts` 导出（`audit.py exports_check`）。
- CP-11-05 应：原子级补充——**Link 链接**（03 · 3.10：默认/强调/弱化/危险/外链 × 三尺寸；长文常显下划线；移动热区 ≥44）。
- CP-11-06 应：跨端与性能组件——**Cascader 级联选择**（03 · 3.5.5 / 10 · 10.11.3，层级 ≤4）、**ResponsiveView 响应式适配容器**（10 · 10.11.1，按容器宽度切 table/condensed/card，单分支渲染）、**VirtualList 虚拟长列表**（10 · 10.11.2，>50 项 / >200 行 / DOM 行 >300 必须窗口化）。
- CP-11-05 应：引擎基底 Arco（React），Semi 对齐矩阵见 08；自包含轻量适配仅限 GmTag/GmSteps 类。
- CP-11-06 应：组件新增完成 index.ts 导出 + README + coverage 计数 + `npm run typecheck`（CI）。
- CP-11-07 应：按钮文字+图标组合遵循 03 · 3.2.5——容器 inline-flex 几何居中、gap（S6/M8/L8）、图标档（L18/M16/S14）且 flex:none 防挤压；装饰图标在有文字时 aria-hidden，纯图标钮须 aria-label；箭头类 hover 右移 2px。
- 组件细节（03.2 Button 全谱、03.6 徽章、03.7 表格、10/11 双端、13 领域）→ 以对应 NN 章为准（本节不重复全表）。
