## 2 条款
- DB-16-01 应：结构 KPI 条（4–6 卡）→ 主趋势 → 对比/构成 → 明细；数据色序 12.3.3（Rose-500 首序等），语义色只表状态。
- DB-16-02 应：图表选型（04 章）——趋势折线/面积（描线 draw 1s）、对比柱状（成长 900ms 错峰）、构成环/饼（中心总数）、分布按 04。
- DB-16-03 应：大屏（04/07.6）16:9、12 列、层叠 ≤3；只动 transform/opacity；实时刷新 draw 重绘或 2.4s 呼吸；文字 ≥14、数字 tabular。
- DB-16-04 应：状态——加载骨架+Spin(role=status)；空 GmEmpty；错误三通道+重试；断连呼吸警示。
- DB-16-05 不应：异常闪烁当装饰；图表色挪用语义；无标签图例（读屏需可读文本）。
- 图表组件与示例见 goodmom-ui 与 preview/index（图表模块交互）——以 04 章为准。
