# Part 17 · 导航规范（标准正文）

> 状态：✅ 现行 · 版本 V1.0 · 维护指针：`docs/审查决策记录.md`
> 适用范围：侧栏/顶栏/页签/移动导航与站点菜单。
> 用词：应/宜/可；编号 `17-xx`。

## 1 目的与适用范围
## 2 条款
- NV-17-01 应：PC 左侧玻璃侧栏（03.4.1）——悬浮玻璃柱（左距 16px、圆角 22–28）；结构 Logo→主导航（图标+文字）→分组标题→底部用户/设置；展开 232–260px、收起仅图标约 80px。
- NV-17-02 应：选中态=渐变玻璃芯片（紫/品牌渐变）＋柔光；禁止传统 Dashboard 左边框粗条；徽标白底紫字。
- NV-17-03 应：顶栏（03.4.2）——面包屑/标题（左）、全局搜索（中 280–360）、状态与用户（右）；在线绿点。
- NV-17-04 应：分段/页签（03.4.3）——分段玻璃底+滑块 280ms 平移；页签选中底部紫渐变小条 scaleX；移动页签横滑热区 ≥44。
- NV-17-05 应：站点悬停下拉带桥接带（hover bridge）；统一导航/logo；HTML 无 .md 链接（audit html-md）。
- NV-17-06 应：断点与形态——≥1281 侧栏可用；≤1280 顶栏页签；移动 TabBar(3–5)+NavBar 替代侧栏（10.3，移动禁侧栏）；断点 767/1024/1366（audit bp）。
- NV-17-07 不应：侧栏选中用左边框粗条；移动端左侧栏；菜单无 hover 桥接带。
