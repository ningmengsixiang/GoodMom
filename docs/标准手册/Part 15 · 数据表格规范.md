## 2 条款
- TB-15-01 应：PC 玻璃表格（03.7）——表头次级字（#4F5B6E，D7b）、行 hover 淡白底、分隔 rgba(58,52,84,.08)、操作列右对齐内联（17.2 基线 .ops）。
- TB-15-02 应：排序/筛选给语义（aria-sort/aria-expanded）；长文本省略+title；关键列固定需标注且保留表头语义。
- TB-15-03 应：行状态——loading 骨架行/局部圈；错误行内重试；空态 GmEmpty（图标 48）；禁用行置灰并说明。
- TB-15-04 应：移动降级（10.5.3）表格→卡片列表（字段名-值）或横滑窄表；禁止行内分页（用加载更多/到底提示）。
- TB-15-05 应：医疗结论列颜色+文字（异常/阳性/阴性词），装饰色不干扰。
- TB-15-06 不应：全宽贴地边框；hover 仅色差传达可点性。
- TB-15-07 应：宽表/减列表格/卡片流三形态由**响应式适配容器**按容器宽度统一切换（10 · 10.11.1：≥1024／768–1023／≤767），禁止各页自定断点；排序/筛选/分页状态切形态不重置。
- TB-15-08 应：超过 200 行的表格必须窗口化行渲染（10 · 10.11.2，表头/列固定不参与回收）；窗口内禁逐行 backdrop-blur；卡片流用 `role=list/listitem` + `<dl>` 语义。

## 3 落地实现（V2.9 补齐）

合并为唯一首页后，**5 个页面各有一份自己的表格**，实测漂移成：表头字号 11 / 11.5 / 12px
（02 · 2.2.2 的类型阶最小档是 caption 12）、字重 500 / 600（03 · 3.7 要求 600）、
表体 12.5 / 13px（类型阶里「表格正文」就是 body-sm 14/20）、分隔色 `rgba(…)` 有 .06 / .08 / .09 三种、
行高 49 / 51 / 55 / 57（03 · 3.7 是 44–52）、操作列有的靠行内 `style="text-align:right"` 有的没有、
且同时存在 `.op` 与 `.ops` 两个名字。

现收敛为**外壳里的一份配方**（`scripts/build-site.py` 的「数据呈现层」）+ 页面只加 class：

| 项 | 取值 | 依据 |
| --- | --- | --- |
| `.gm-tbl` | body-sm 14/20 · `tabular-nums` 落整表 | 02 · 2.2.2 / 17 · 17.2.2 |
| 表头 | 14px · **600** · 次级色（`--lg-text-secondary`） | 03 · 3.7 / TB-15-01（D7b） |
| 单元格 | `padding:12px 14px` · **不折行** | 行高算术：12+20+12+1 = 45 |
| 行高 | 44–52 | 03 · 3.7；内联元素一律 ≤26（头像/徽章/mini 按钮）→ 最坏 51 |
| 分隔 | `--lg-border-hairline solid var(--lg-divider)` | TB-15-01 |
| 操作列 | `col-ops`（右对齐）+ `.ops` 内联动作组，行内链接 ≤3 | TB-15-01 / 17 · 17.2.3 |
| 横滑 | `.gm-tbl-wrap{overflow-x:auto}`（**不得**给 `<table>` 自己加 `display:block`，那会抹掉表格语义） | TB-15-02 / TB-15-04 |
| 表头语义 | 每个 `<th>` 必须 `scope="col"` | TB-15-02 |

**为什么"不折行"是硬要求**：折行会把行高从 45 涨到 65，直接顶破 03 · 3.7 的 44–52；
窄视口按 TB-15-04 走「横滑窄表」，横向滚动交给 `.gm-tbl-wrap`，文档本身不溢出。
同理，单元格内的**直接子元素**必须 `flex-wrap:nowrap` —— 页面里 `.block span{flex-wrap:wrap}`
这类通用规则会把头像与文字拆成两行（实测 `.cell-av` 55px → 行高 80px）。

守门：`python3 scripts/audit.py --only data-present`（静态配方与数值）+ `scripts/page-qa.mjs`
的 `tbl-head-type` / `tbl-body-type` / `tbl-row-height` / `tbl-th-scope` / `tbl-ops-align` /
`tbl-tabular` / `tbl-display`（渲染级实测）。
- 组合/间距细节以 03.7 与 17 章为准。
