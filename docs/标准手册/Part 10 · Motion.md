## 2 Token（07.2 权威）
| Token | 值 | 用途 |
| --- | --- | --- |
| fast | 120ms | 按压、即时反馈 |
| base | 220ms | hover/颜色过渡 |
| slow | 400ms | 状态过渡、弹层 |
| entrance | 800ms | 面板/页面入场（多卡 60–90ms 错峰） |

## 3 条款
- MO-10-01 应：组件配方遵守 07.3——按钮 sheen 0.8s、按压 scale(.96)120ms、loading 圈 0.9s；开关 spring 300ms；分段 280ms；弹层 250+320ms；Toast 320→驻留 2.4s→240ms；骨架 1.15s；列表错峰 60ms×n。
- MO-10-02 应：分级 M1–M4 使用（M1 状态反馈/M2 悬浮展开/M3 强调/M4 仅在线呼吸）；M4 只给实时状态。
- MO-10-03 应：红线——只动 transform/opacity；全屏 backdrop-blur ≤6 节点；动效不承载唯一信息（颜色+文字双通道）。
- MO-10-04 应：`prefers-reduced-motion` 全局降级（07.5/07.9）。
- MO-10-05 应：医疗结果/风险状态不配庆祝动画；红级警示不可一键忽略（15.2/24）。
