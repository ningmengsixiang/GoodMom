# Part 22 · Mobile 端规范（标准正文）

> 状态：✅ 现行 · 版本 V1.0 · 维护指针：`docs/审查决策记录.md`
> 适用范围：手机（≤767）形态、触控与移动组件。
> 用词：应/宜/可；编号 `22-xx`。

## 1 目的与适用范围
## 2 条款
- MB-22-01 应：骨架（10.3）NavBar（返回/标题/操作）＋TabBar（3–5 玻璃胶囊）；内容单列卡片流。
- MB-22-02 应：触控——热区 ≥44×44、关键 ≥48；输入高 44、字号 ≥16；页面两侧留白 ≥16。
- MB-22-03 应：输入/选择——Select/Picker 底部弹层（不遮键盘）；日期/开关/步进/上传按 11.2；错误就近+底部操作表承担 Popconfirm。
- MB-22-04 应：表格/列表→卡片或横滑；分页改加载更多+到底提示。三形态由**响应式适配容器**统一判定（10 · 10.11.1：容器宽度 ≥1024 table／768–1023 condensed／≤767 card），禁止各页自定断点；状态不随形态切换重置。
- MB-22-07 应：长列表窗口化（10 · 10.11.2：>50 项或单次 DOM 行 >300）——固定行高 + overscan 4、吸顶用 Sticky、行内左滑用 SwipeAction、距底 4 项触发加载更多；窗口内禁逐行 backdrop-blur；`aria-posinset/aria-setsize` 必做。
- MB-22-08 应：级联选择在移动端用底部多列 Picker（10 · 10.11.3），不得铺开桌面式横向多列面板。
- MB-22-05 应：反馈 Toast 居中偏上；底部抽屉/弹层常用；FAB 抬升于 TabBar 之上（08.2.1）。
- MB-22-06 应：安全区 env()，TabBar 不压内容（11 章验收）。
- 预览：site/index.html#preview-mobile；断点 ≤767。
