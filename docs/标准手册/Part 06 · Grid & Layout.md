# Part 06 · Grid & Layout（标准正文）

> 状态：✅ 现行 · 版本 V1.0 · 维护指针：`docs/审查决策记录.md`
> 适用范围：跨端布局栅格、断点体系与页面壳结构。
> 规范性用词：应/宜/可；条目标号 `06-xx`。

## 1 目的与适用范围
## 1 条款
- GR-06-01 应：断点只允许四档 + 大屏增强：≤767（手机）/ 768–1023（iPad 平板）/ ≥1024（PC）/ ≥1366（大屏增强，内容限宽分级 1300/1440/1600/1820）；偏离触发 audit `bp` 检查。
- GR-06-02 应：侧栏可用边界 ≥1281；≤1280 一律回顶栏页签形态。
- GR-06-03 应：栅格——PC 12 列（17.1.1）；iPad 8:4 左列表右详情或自适应卡流；Mobile 单列。
- GR-06-04 应：页面壳 `wrap(限宽居中) → 顶栏/侧栏 → 内容区`；层叠面板 ≤3（17.3.3）。
- GR-06-05 应：组合顺序（17.3.1）头像→标题→标签/状态→数值→操作→说明；操作列右对齐（17.2 内联基线）。
- GR-06-06 应：布局弹性可换行，禁止固定像素列宽；移动禁止左侧栏与行内分页。
- GR-06-07 应：每页一个主行动（视觉与键盘优先）。
