## 2 条款
- UX-13-01 应：反馈六则（07.8 通则）——hover/press 二选一；focus 可见（:focus-visible 环，禁裸 outline:none）；disabled 给理由；loading 不换内容；错误三通道；每次交互 ≤250ms 起反馈、等待即 loading。
- UX-13-02 应：确认类操作三段式：确认 → busyFor 忙碌（600–950ms）→ 结果反馈（Toast/行状态动画）。
- UX-13-03 应：AI 智能体回复先打字点再出内容；数据刷新不整页闪白（骨架+过渡）。
- UX-13-04 应：页面编排——视图切换淡入 0.3s、多卡 60–90ms 错峰、KPI easeOut 700ms–1s、图表 draw 1s。
- UX-13-05 应：医疗领域——结果状态不嬉皮；红级风险置顶且不可一键忽略（15.2）。
- UX-13-06 不应：纯 hover 依赖的必需操作（键盘可达见 Part 23）；无忙碌态重复提交。
