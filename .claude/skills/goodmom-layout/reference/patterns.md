# 页面组合范式（骨架树）

> 组合 = 基元按固定「顺序 + 间距 + 对齐」装配；**禁止自由摆放**。
> 通用前提：状态（排序/筛选/分页/已选）由**页面**持有；容器只负责渲染分支。

## 1. 列表 / 表格页（服务对象 · 筛查 · 随访队列 · 疫苗）

```text
页面壳
├── ② 标题区         H1 + 说明 caption + 面包屑(PC)
├── KPI 行（≤4 个，静态不可点）
├── ③ 工具行         筛选 chips / 分段 / 搜索 / 批量操作（+ 计数 live region）
├── ④ GmResponsiveView（同一份数据，按容器宽度切形态）
│   ├── #table      ≥1024   玻璃表格全列（排序/筛选/多选）
│   ├── #condensed  768–1023 减列（对象列 + 结论列 + 操作列），行高 44
│   └── #card       ≤767    行卡片（标题 + 状态角标 + 键值对 + 卡底操作栏）
├── 分页（PC）/ 上拉加载 + 到底提示（≤1023）
└── 空/载/错三态由 PageState 或 GmResponsiveView 的 loading/empty 承载
```

- 每行状态用 `GmStatusTag`，**页面不写色**。
- 操作列：`.col-ops` + `.ops`，行内 **≤3** 个动作，文字链接优先，危险动作最后。
- **>200 行（PC 表格）/ >50 项（移动）** 才上 `GmVirtualList`；低于门槛直接 `map`/`v-for` 更快。
- 空态必须给下一步动作（`GmEmpty` 里放主按钮），但**不能与页面级 Primary 同屏出现两个主行动**（17.1.3）——需要取舍，二选一。

## 2. 表单页

```text
页面壳
├── ② 标题区
├── 步骤条 GmSteps（多步时；`current` 0 起）
├── 分步卡片 GmCard × N（标题 + 字段 + 提示）
│   └── 字段：Arco Form + shared/utils/validators（校验规则唯一源）
├── ⑤ 底操作区  上一步 / 下一步（**唯一 Primary**，PC 右下 / iPad 底部 / Mobile 底部栏）
└── 错误：三通道（可见文案 + 语义色 + aria），**字段错误不用 Toast**
```

- 输入框移动端 **≥16px** 字号（防 iOS 聚焦缩放）。
- 底部操作栏必须接 `env(safe-area-inset-bottom)`。
- 长表单分步：每步一个主行动，全流程 Primary 唯一。

## 3. 详情页

```text
页面壳
├── ② 对象卡头   GmClientCard（头像 46 + 姓名 + 组合标签 + 摘要 + 操作区）
├── 全生命周期轴（阶段色母题；13.4）
├── 两栏（PC 8:4 / iPad 8:4 / Mobile 单列）
│   ├── 左：明细（Descriptions 键值对 / 时间线）
│   └── 右：主图（生长曲线 / 环形）+ 指标说明 + 下一步操作（**唯一 Primary**）
└── 移动端：NavBar → 对象卡 → 卡片列表 → 底部操作栏（Primary 靠左）
```

## 4. 工作台（医护）

```text
顶栏
├── KPI 行（4 个）
├── 左：今日待办表（**只读聚合视图** —— 排序/判状态归 followup 模块，见 19.5.3）
└── 右：快捷工具 / 概览
     └── 风险队列置顶，用五色标签（GmTag five）
```

> 硬规则：**一个状态机只属于一个模块**。`workbench` 不许自己再排一次序、再判一次状态。

## 5. 机构运营 / 数据大屏

```text
12 列网格 · 24px 栅栏
├── 层叠面板 ≤3（04 · 4.5）
├── KPI 卡（最重要）：数字 tabular-nums + 单位 caption 并排（单位不缩小主数字）
├── 主图：折线/面积（面积优先）
├── 数据色序走 12.3.3 品牌默认顺序（8 色循环，禁随机色）
└── 状态色**只表状态**，不表序列；色序**只表序列**，不表状态
```

大屏附加：整体内边距与字号 **×1.15–1.25**；控件最小可点 **≥44×44**；动效 M4 类 ≤5 处同屏循环。

## 6. 移动页（家长端 Low 密度）

```text
NavBar（玻璃，44 返回键，上滑 120px 淡入）
├── 对象卡 / 孕周卡 / 宝宝卡
├── 卡片列表（单列，页边 16，卡间隙 12，列表项 ≥52 高）
├── 下拉刷新 / 上拉加载（距底 4 项触发）
└── 底部 TabBar（3–5 项，距底 12 + safe，圆角 22）或底部操作栏（Primary 靠左）
```

- 一屏 `backdrop-filter` 节点 **≤2**（NavBar + TabBar），其余用半透明白实色近似。
- 一屏一个主行动；移动端**禁止 hover 依赖**。

## 7. 间距与对齐速查

```text
图标-文字     8
同组按钮      8–12
不同组工具行   16–24
卡内区块之间   16–24
卡与卡        24（内容）/ 16（紧凑）
块与块        32–40
页板块        48–72
页边          40(PC) / 24(平板) / 16(移动)
```

图标与文字对齐用 `inline-flex + align-items:center`（详见 SKILL.md 的基线 CSS）。

## 8. 组合类硬约束

| 约束 | 值 |
| --- | --- |
| 同屏大玻璃面板 | ≤3 层 |
| 浮层叠浮层 | 禁止（弹窗内改步骤或抽屉） |
| 一屏 Primary | 1 个 |
| 对象卡状态标签 | ≤3 个 |
| 行内操作 | ≤3 个 |
| 表格单元格内联元素高 | ≤26px（否则顶破行高 44–52） |
| 图标装饰 | 除颜色语义外无额外装饰（禁再套发光/描边彩圈） |

## 9. 验收

```bash
node scripts/layout-gate.mjs     # P0 溢出/白条、P1 出框/重叠/塌陷、P2 被切 —— 必须为 0
node scripts/page-qa.mjs --ci    # 圆角/边框/模糊/字号/热区/焦点环/表格/折叠/曲线
node scripts/mobile-smoke.mjs    # 移动端行为与几何（需静态服务 5288）
```

`layout-gate` 扫描 **71 个页面/视图 × 7 档（320–1920）= 386 次**；320 档（iPhone SE）是三处历史溢出的真凶现场，别只看 375。
