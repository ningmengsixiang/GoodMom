# 页面结构、布局与多端

## 5 级景深：先回答「我在第几层」

| 层 | 名称 | 填充 | 模糊 | 描边 | 圆角 | 阴影 | z |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **L0** | Background 环境层 | 暖象牙底 + 环境光斑 | — | — | — | — | 0 |
| **L1** | Main Glass 主玻璃 | `.14` | 48px | `.45` | 40 | `--lg-shadow-sm` | 10 |
| **L2** | Floating Components 组件层 | `.22` | 32px | `.55` | 22–28 | `--lg-shadow-md` | 20 |
| **L3** | Floating Controls 控件层 | `.35` | 20px | `.70` | 20 | `--lg-shadow-lg` | 30 |
| **L4** | Light & Reflection 光效层 | `.60` | 40px | `.85` | 28 | `--lg-shadow-xl` | 40 |

规则：层级越高 → 玻璃越实/越白/模糊越弱/阴影越紧；圆角可略小但**永不 <16px**；L4 只做加法（白色高光 + 彩色漫射辉光，**无硬轮廓光**）。
**组合上限**：同屏大面板 **≤3 层**；**浮层不叠浮层**（弹窗内不再开弹窗 → 改步骤或抽屉）。
⚠️ L4 的模糊(40) > L3(20)、圆角(28) > L2/L3，与「递减」规则相反 —— 照数值用，别推导规律。

## 页面壳（自上而下六段）

```text
① 导航/顶栏       Logo(≤32) + 分组菜单 + 全局搜索 + 用户
② 页面标题区      H1(≤26) + 说明 caption + 面包屑(PC)
③ 工具行(可选)    筛选 chips / 分段 / 搜索 / 批量操作
④ 内容区          12 列(PC) / 8-4 分栏(iPad) / 单列(Mobile)
⑤ 底操作区(可选)  PC 右下角 / iPad 底部「保存并提交」/ Mobile 底部操作栏
⑥ 页脚           版权 + 站点链接
```

**真实壳层参数**（别自创）：React 应用壳侧栏 **240px**、顶栏 **56px**、内容 **1080px**；独立产品页侧栏 **252→80px**、内容 **1220px**；站点顶栏 60/53、内容 **1240px**。

**每页只放一个主视觉焦点**：Primary 主按钮**每页唯一**；数据/表格页 → 左上 KPIs；详情页 → 对象卡头；表单页 → 步骤条。

## 网格与断点

| 端 | 断点 | 列数/形态 | 栅栏 | 页边 | 最大内容宽 |
| --- | --- | --- | --- | --- | --- |
| PC | `≥1024` | 12 列 | 24 | 24–40 | 1180–1220（实装 1080/1220/1240） |
| 平板 | `768–1023` | 8:4 分栏 或 自适应卡片流 | 16 | 24（增量 20） | 同 PC 分栏内 |
| 移动 | `≤767` | 单列卡片流 | 卡间隙 12 | 16 | 真机框 max 430px |
| 大屏增强 | `≥1366` | 12 列（限宽分级） | 24 | — | 1300 / 1440 / 1600 / 1820 |

- **页面媒体查询只允许这四档**（其他档位 `audit.py bp` 会 WARN；当前有 7 处待收敛）。
- **禁止固定像素列宽**；布局必须弹性可换行。侧栏可用边界 **≥1281**，`≤1280` 回顶栏页签。移动端**禁左侧栏与行内分页**。
- **纵向节奏**：小节间 ≥24，大板块间 **48–72**。

## 响应式：容器观测 vs 视口断点（最容易写错）

| 场景 | 用什么 |
| --- | --- |
| 同一页里**同一份数据**按容器宽度切形态 | **`GmResponsiveView`** |
| 页面级骨架（侧栏收起、页边、栅格列数） | 视口媒体查询 |
| 组件内分支 | `useMediaQuery(MQ.*)` / `shared/constants/breakpoints` |

**为什么**：同一页里多个容器宽度不同，用视口断点**必然有一个错**。

```vue
<!-- 阈值默认 { condensed: 1024, card: 767 } -->
<GmResponsiveView :data="rows" :loading="loading">
  <template #table="{ rows }"><table>…</table></template>
  <template #condensed="{ rows }">…</template>
  <template #card="{ rows }"><GmCard v-for="r in rows" …/></template>
</GmResponsiveView>
```

**硬要求**：**同一时刻只渲染一个分支**（不做 CSS 双渲染后隐藏 —— 读屏会读两遍）；排序/筛选/分页状态由**页面**持有，切形态**不重置**；卡片列表首屏骨架 **≥3 张**。

**表格降级三形态（只换形态、不换信息）**

| 形态 | 宽度 | 字段映射 |
| --- | --- | --- |
| `table` | ≥1024 | 全列，可排序/筛选/多选 |
| `condensed` | 768–1023 | 减列（对象列 + 结论列 + 操作列）；次要列折进抽屉；**行高降到 44** |
| `card` | ≤767 | 第 1 列 = 卡片标题；状态列 = 角标；其余列 = 键值对；操作列 = 卡底操作栏（≤3 个，主行动全宽） |

卡片键值对必须覆盖表格**全部可见列**（列 >6 时保留前 6 + 「查看全部」）；分页改「上拉加载 + 到底提示」。

> ⚠️ 仓库里**没有任何原生 CSS 容器查询**（`@container` / `container-type` 全仓 0 命中）。「容器查询」= JS 侧 `ResizeObserver`。不要用 `@container` 复刻。

## 移动端硬指标

| 项 | 值 |
| --- | --- |
| 触屏热区 | **≥44×44**；关键按钮/主行动 **≥48**；桌面鼠标 ≥40 |
| 正文字号 / 输入框 | **≥16px**（防 iOS 聚焦缩放） |
| 按钮高度 | L **48** / M **44** / S **36** |
| 列表项 | **≥52 高**，信息两行 |
| NavBar | 返回键 **44 圆形**；标题 18/600；上滑 **120px** 后玻璃淡入（240ms）；根页**整键移除**返回键（**不是置灰** —— 置灰按钮键盘不可聚焦，会同时触发「焦点不可见」与「禁用无理由」） |
| TabBar | **3–5** 项；距底 `12px + safe-bottom`；圆角 **22**；`padding:6px`；项高 **56**；图标 22–24 + 标签 **10–11px**（用 `--lg-text-secondary` —— tertiary 在玻璃底上只有 2.30:1）；激活项玫瑰渐变胶囊 + 上浮 **-4px** + 平移 260ms |
| 安全区 | `env(safe-area-inset-*)` **必接**；TabBar/NavBar/底部主行动之上加 SafeArea，**内容卡片不重复加**；内容预留「TabBar 高 + 12 + safe」 |
| 玻璃 | 同屏 `backdrop-filter` 节点 **≤4**（家长端 ≤2：NavBar + TabBar）；**`blur ≤32px`**；不劫持页面滚动（内部滚动需 `overscroll-behavior:contain`） |
| 弹层 | **底部优先**；一次一个；Modal 高 ≤92%；BottomSheet 顶部圆角 20 + 遮罩白 `.18` + blur 8；ActionSheet 操作行 56、上滑 320ms |
| 组件几何 | Switch 48×28 / 滑块 24；Checkbox 视觉 22、热区 44；分段高 36–40、段间 4、≤6 段；SearchBar 40–44 圆角 18；Cell 52–56；Cascader Picker 列高 268、单列宽 ≥112；OTP 44×52 圆角 18 间距 8；Upload 86×86 圆角 18；Result 图标 56–64、入场 500ms |
| 其它 | 移动端**禁 hover 依赖**；PC **禁只做 tap 态**；横竖屏切换**状态不丢** |

## 对齐与组合基线

```css
.icon-text{display:inline-flex;align-items:center;gap:8px}
.inline-icon{display:inline-block;vertical-align:-2px}
.icon-btn{width:15-18px;height:15-18px;flex:none}
button{display:inline-flex;align-items:center;justify-content:center;gap:8px}
```

| 场景 | 规则 |
| --- | --- |
| 按钮 + 图标 | `inline-flex + center`，图标 15–18 不缩放文字行 |
| 行内文字前图标 | 12–14px 小图标用 `vertical-align:-2px` 或 flex 包裹 |
| 状态标签 | 整体 `inline-flex`，色点 6–8px，垂直居中 |
| 头像/色块 | `inline-flex center` + `flex:none`（防被行拉伸变形） |
| 表格单元格 | 统一 `vertical-align:middle` |
| 表格操作列 | 列头与单元格**都**加 `col-ops`；动作组 `.ops` 右对齐 `flex-wrap:nowrap`；行内操作 **≤3** 个、文字链接优先、按钮用 `mini`(26)；单元格内联元素 **≤26px**（否则顶破行高 44–52） |
| 导航 Logo | 高 20–32、圆角裁切、`object-fit:cover` |

**组合基元顺序（禁止自由摆放）**

```text
对象组合：头像 → 名称 → 状态标签(≤3) → 摘要/副信息 → 右侧操作区
操作组合：查看 → 编辑 → 主要动作(Primary) → 危险动作(最后, danger)
列表行：  状态点/图标 → 主文本 → 次文本(caption) → 关键数值(tabular) → 操作
详情页右栏：主图(曲线/环形) → 指标说明 → 下一步操作按钮（唯一 Primary）
```

## 布局类硬红线

| ⛔ 禁止 | 原因 |
| --- | --- |
| 用视口断点切表格/卡片形态 | 同页多容器宽度不同，必有一个错 |
| CSS 双渲染后隐藏切换分支 | 读屏读两遍；移动端白渲染一份 |
| 固定像素列宽 | 布局无法弹性换行 |
| 横向溢出 / 页面级滚动条 | `layout-gate` **P0**，必须为 0 |
| 页面底部/侧边留白条（背景未绘制） | `layout-gate` **P0**（真因通常是独立页没重置 UA 默认 `body{margin:8px}`、`html` 又没画底色） |
| 元素出框 / 块级重叠 / 布局塌陷 | `layout-gate` **P1** |
| 文字被裁切 | `layout-gate` **P2** |
| 热区 <44、字号 <12px | `layout-gate` **P3**（登记不阻塞，但属待办） |
| 同屏 >3 个大玻璃面板 / 浮层叠浮层 | 视觉层级崩塌 |
| 每页多个 Primary | 焦点消失（17.1.3） |

```bash
node scripts/layout-gate.mjs        # P0/P1/P2 必须为 0
node scripts/page-qa.mjs --ci       # 圆角/边框/模糊/字号/热区/焦点环/溢出/emoji
```
