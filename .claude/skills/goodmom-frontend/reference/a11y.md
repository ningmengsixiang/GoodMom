# 无障碍基线（WCAG 2.2 AA）

组件库已内建大部分契约，**页面的责任是不要把契约用坏**。以下每条都有对应红线编号。

## 语义正确（R6）

| 场景 | 正确 | 错误 |
| --- | --- | --- |
| 导航到别的页面 | `<GmLink href="/x">` → `<a>` | `<GmButton @click="router.push()">`（读屏不播报为链接、无法中键新窗口） |
| 触发一个动作 | `<GmLink @click="fn">` 或 `<GmButton>` | `<a href="#">` （播报为链接、右键出现"新标签页打开"） |
| 关闭弹窗 | `<GmButton shape="circle" aria-label="关闭">` | `<span @click>✕</span>`（不可聚焦、无名称） |

**判据**：问「点它会发生什么」。换地址 = 链接；改变状态 = 按钮。

## 名称与标签

- 仅图标按钮/链接**必须**给 `aria-label`（`GmButton` 的 `ariaLabel` / `GmLink` 的 `ariaLabel`），否则读屏只播报"按钮"。
- `GmAvatar` 独立承载信息时传 `label`（如"张女士"）；旁边已有姓名则不要传（避免重复播报）。
- 表单控件必须有关联 `<label for>`；placeholder **不能**替代 label（填完就消失）。
- 图标一律 `aria-hidden="true"`，语义由文字承担。

## 键盘可达（R8）

- 所有交互元素必须能 Tab 到，且 `:focus-visible` 可见。**禁止 `outline:none` 而不给替代样式。**
- 组合控件用 **roving tabindex**，不要给每个子项都设 `tabindex=0`：
  - `GmRiskPicker`：仅选中项可 Tab，组内用 ←→↑↓ / Home / End 切换。
  - `GmCascader`：仅高亮项可 Tab，列内 ↑↓ 移动、→ 进列、← 回列、Enter 选中、Esc 关闭。
- **弹层关闭必须归还焦点**（`GmCascader` 已实现）。自建弹层时：记录触发元素 → 关闭时 `focus()` 回去。
  否则焦点掉到 `<body>`，键盘用户直接迷路。
- Focus trap：模态弹层需把 Tab 限制在层内（`role="dialog" aria-modal="true"`）。

## 颜色不单独承载信息（R5）

状态必须「色点 + 文字」双通道。`GmStatusTag` / `GmTag` 默认带色点；自建状态展示时：

```vue
<!-- 错：只能靠颜色区分 -->
<span style="color: var(--lg-sem-risk)">●</span>
<!-- 对：色点 + 文字 -->
<GmStatusTag>高危</GmStatusTag>
```

图表同理：每条线/柱必须有图例或直接标注，不能只靠颜色。

## 对比度

| 场景 | 要求 |
| --- | --- |
| 正文/标签文字 | ≥ 4.5:1 |
| 大字号（≥18.66px 粗体 或 ≥24px） | ≥ 3:1 |
| 图标/边框等非文字 | ≥ 3:1 |

**已知高危组合（R1）**：品牌亮粉（Rose-300~500）上放白字只有 2.9:1。
需要「实底 + 白字」时用 D5 深档（`--mmh-solid-*`）；主行动用渐变 + 深字 `--lg-text-on-accent`。

已实测工具：`scripts/a11y.py`（静态走查）、`scripts/a11y-dom.py`（无头 Chrome DOM 实测）。

## 触达热区（R7）

移动端（≤767px）可点元素热区 ≥44×44。库内已处理：

- `.gm-link` 移动端用 `::after` 向外扩 11px 补足热区。
- `.gm-risk-it` 移动端 `min-height:44px` 且撑满一行。
- `.gm-client-ops` 移动端换行到底部（避免和姓名挤在一行导致热区重叠）。

自建按钮时注意：`.gm-btn--mini`（26px）达标的是**桌面**密度，移动端要用 `size="default"` 以上。

## 动效

`prefers-reduced-motion: reduce` 时组件库全局把动画/过渡压到 `.01ms`。
自写关键帧动画时把选择器加进 `src/styles/base.css` 的兜底列表，或自行加媒体查询（R10）。

## 读屏细节

- 加载态：`GmSpin` / `GmSkeleton` 用 `role="status"`，文字承担语义。
- 进度：`GmProgress` 输出 `role="progressbar"` + `aria-valuenow/min/max` + **`aria-valuetext` 人话**（如"已完成 3/5 项"）。纯百分比读屏体验很差，务必传 `valueText`。
- 长列表：`GmVirtualList` 每项带 `aria-posinset` / `aria-setsize`，读屏才能说"第 12 项，共 3000 项"。
- 弹层：`role="dialog"` + `aria-modal="true"` + `aria-label`。
- 步骤：`<ol>` + `aria-current="step"` 标当前步。
- 屏幕阅读器专用文字用 `.gm-sr-only`（如外链的"（新窗口打开）"）。
