  1. AI 出图 → 打开 [05-AI生成Prompt库.md](#ch-05)，复制 Master Prompt 或对应行业 Prompt，粘贴负面提示词。

  4. 视觉对照 → 浏览器打开 [preview/index.html](preview/index.html) 实时查看效果（含微交互演示，悬停、按压、开关、分段控件等均可直接操作）。

  6. 完整示例页 → 打开 [preview/examples.html](preview/examples.html)，按“下一页”顺序走完 7 套常用页面。

一句话设计规范

透明的材质、柔和的光、漂浮的结构、克制的颜色、极简的文字、强烈的空间层级。

Design DNA（妈咪好 GoodMom 速览）

维度设计原则
材质Translucent Liquid Glass（高透亚克力，非纯白）
结构Floating / Layered（一切悬浮，多层级）
圆角24–48px（一切皆圆，拒绝直角）
边框1px translucent white
阴影Large / Soft / Diffused（无纯黑硬阴影）
背景奶杏暖调（蜜桃光斑 + 淡紫柔光，非纯白非纯黑）
主色蜜桃粉（--mmh-rose-*；液态紫=氛围/引擎档）
辅色薄荷=儿保正向 · 蓝=信息 · 琥珀/珊瑚=注意/风险
点缀淡紫柔光（特殊协作 / 技术焦点）
光效Ambient / Volumetric（漫射柔光，禁止霓虹）
图标LG 线性图标 24×24（GoodMom 版 77 枚 / 10 类）
字体Inter / SF Pro；中文 PingFang SC / MiSans
信息密度Medium
空间感Very High（5 级景深）
视觉关键词温暖可信 · 液态玻璃 · 医疗克制 · 生长曲线
禁止Neon / Flat / Clutter / 幼齿卡通 / 恐慌化文案

1.2 十大视觉特征

特征一：大面积透明玻璃容器

整个 UI 被包裹在巨大的透明玻璃面板中，而非白色卡片：

属性建议值
Glass Opacity15–35%（底色半透明，透光）
Background Blur25–60px
Border1–2px 半透明白 rgba(255,255,255,0.45)
Corner Radius28–48px
折射轻微，边缘与高光处体现
玻璃后面能看到环境，玻璃不是遮挡，而是「过滤光」。

特征二：所有元素「漂浮」

按钮、输入框、卡片、Checkbox 不是平铺在画布上，而是悬浮在玻璃空间中，每个组件有独立的空间层级。

特征三：中性环境 + 少量高饱和彩色光源

色彩克制：底色全部暖中性（象牙 / 米色），彩色只作为「光源」少量出现。这是高级感的来源。

特征四：柔和光影（Ambient + Volumetric）

紫 / 青 / 粉光晕漫射在空间里，绝无霓虹光带、绝无硬阴影。观感接近电影布光的 diffuse / soft / atmospheric。

特征五：无纯黑阴影

传统 0 4px 10px #000 被禁止。使用大范围、低不透明度、高模糊、多层的带色相阴影（蓝紫调）。

特征六：超大圆角

一切皆圆：页面容器 36–48px，卡片 22–36px，控件 16–28px。拒绝直角、小圆角与锐利边缘。

特征七：克制排版

大标题不超重（Weight ≤ 700 且通常 600），层级靠字号、字重与留白区分，信息密度 Medium。

特征八：玻璃材质图标

图标不是扁平线性，而是「用玻璃做成的小实体」：半透明、柔和高光、微 3D、圆润、内部渐变。

特征九：明暗与透明度分层

用玻璃不透明度区分层级：越重要的控件越「实」（透明度越低 / 更白），越底层的面板越「虚」。

特征十：留白与空间感

页面留白慷慨，通过 5 级景深（见 1.4）制造「空间操作系统」的纵深感。

1.4 空间层级系统（5-Level Depth System）

这是本设计语言最值得复用的逻辑。任何页面都必须能回答：「我处在第几层？」

LEVEL 0  Background（环境层）
│          暖象牙背景 + 环境光斑（紫 / 青 / 粉 / 白，漫射）
│
LEVEL 1  Main Glass Surface（主玻璃层）
│          巨大半透明玻璃面板，包裹整块内容
│
LEVEL 2  Floating Components（组件层）
│          卡片 / 输入框 / 按钮 / 图表面板 —— 悬浮于主玻璃之上
│
LEVEL 3  Floating Controls（控件层）
│          图标按钮 / 徽章 / 开关 / 气泡 —— 最接近用户手指
│
LEVEL 4  Light & Reflection（光效层）
│          高光边缘、折射高光、渐变辉光 —— 负责「材质真实感」

层级规则：

  1. 层级越高，玻璃越实、越白、模糊越弱、阴影越紧（Level 1 → Level 3 递减不透明度区间）。
  2. 层级越高，圆角可以越小（但仍 ≥16px）。
  3. 光效层（L4）只做加法：永远表现为白色高光 + 彩色漫射辉光，不出现硬轮廓光。
  4. 任意两个相邻层级之间保持清晰的视觉间距（阴影 + 留白）。

1.5 渐变系统（Liquid Gradient）

不使用普通的两端渐变，使用「液体渐变」——像光在玻璃内部流动：

推荐（3 段柔流）：
  Purple ──▶ Blue ──▶ Cyan
  Peach ──▶ Pink ──▶ Purple ──▶ Cyan

要求：

  • 色相过渡柔和，不出现生硬的色阶断带；
  • 渐变通常配合 白色高光 overlay 使用（linear-gradient(160deg, rgba(255,255,255,0.9), transparent 45%)）；
  • 大面积渐变仅限：主背景氛围、品牌主视觉、图表高亮描边、图标内部。

03 · 组件规范

所有组件遵循同一句法则：悬浮、透明、圆润、柔光。组件由「玻璃底 + 白色高光 + 柔色阴影」三层构成，见 [02 · 5](#ch-02) 玻璃 Token。

04-数据可视化规范

04 · 数据可视化规范

大屏/图表的高级感来自 玻璃面板 + 克制的图表 + 数据即焦点。图表只做 1–3 个视觉层次，数据永远在最上层。
数据色序与状态色见 [02 · 2.1.5 / 2.1.6](#ch-02)。

4.1 图表设计总原则

原则说明
数据最亮数据图形（线/柱/点）用全饱和主色；网格/坐标/背景一律退后
无伪 3D禁止立体柱、挤压饼、透视环——玻璃材质 3D 在"容器"，不在"图表"
无霓虹描边线条发光仅允许主序列白色内芯 + 紫辉光 8%（2px 高亮线）
玻璃容器图表面板 = 玻璃卡（L2），图表本身不画玻璃阴影
纵轴起点诚实柱状图不截断误导；截断需在轴上标注
数字优先轴上数值 12px 三级色；关键读数用 --lg-num-md 展示在卡内
动效克制入场 0.6–1s 淡入上浮；实时数据 1.2s 缓动过渡；无旋转闪烁
状态色即语义红/黄/绿只表状态，不作装饰；同一屏绿≤3 处、红≤2 处

4.2 图表公共规格

空态：     无数据区域显示 3 点呼吸灰点 + 淡白玻璃圆角占位
Legend：   白玻璃 chip，色点 8px，caption 文字

4.3 图表类型规范

4.3.1 KPI 总览卡（最重要）

  • 主数字 --lg-num-xl（大屏 48–64），600 字重，tabular-nums。
  • 副行：变化率（↑绿 / ↓红，用状态色）+ 口径说明（caption 三级色）。
  • 迷你趋势 sparkline：2px 紫线 + 40% 透明度紫渐变填充，圆角封边。
  • 可选玻璃小图标（安全/云/AI 主题），置于数字左侧或右上。
  • 状态 KPI（如"今日告警"）：数字用对应状态色 600。

4.3.2 折线 / 面积趋势

主序列：2.5px 紫500，端点白色 6px 圆点 + 紫描边
面积：  紫500 → transparent 的垂直渐变，起点 opacity 0.18
次序列：青色 500 / 蓝色 500，宽度 2px；数据超过 3 序列改多面板或下钻
高亮：  重点时刻加玻璃 point 卡片
虚线：  预测/基线用 2px 虚线 三级色

4.3.3 柱状 / 条形图

  • 柱：圆角 6–8px（顶部圆角），紫渐变底（Liquid Purple）或同色 100→500 渐变。
  • 对比序列用青/蓝，最多 2 序列；禁止堆叠超过 3 层。
  • 横向条形：行高 20–24，圆角 10，数值标注在条右 13px 600 字重。
  • 负值/告警条用对应状态色。

4.3.4 环形图（Donut）

  • 环宽：粗 22–26px（大屏）展示占比，或细 10px 做"完成度"装饰。
  • 主段紫 500 起，按数据色序顺时针排列；缝隙 2px 用背景色隔离（玻璃切缝）。
  • 中心：主值 --lg-num-md + caption 单位，两级居中。
  • 图例在右侧白玻璃 chip 列表，值 tabular-nums。
  • 百分比之和必须 =100%；禁止 ≥8 段（合并为"其他"灰段）。

4.3.5 雷达图

  • 网格：3–4 层极淡多边形（rgba(58,52,84,0.06)）。
  • 填充：紫 500 30% 透明度，描边 2px 紫 500；对比组用青色。
  • 顶点标签 12px 次级色；顶点处加 4px 白点 + 紫描边。

4.3.6 散点 / 气泡

  • 气泡：玻璃质感（半透明白 + 白描边 + 内部高光），核心色紫/蓝。
  • 异常点用红色，2s 轻微脉动（≤3 个）。
  • 参考线 1px 虚线三级色。

4.3.7 拓扑 / 关系网络（安全、云架构核心场景）

  • 节点：玻璃圆角矩形/圆形 = 服务、资产、设备；图标用 3D 玻璃图标。
  • 节点状态：外圈 2px 状态色（绿在线 / 黄告警 / 红故障），同色 0.15 呼吸光。
  • 连线：1.5px 灰紫 rgba(154,120,255,0.35)；活跃流量连线 = 白芯 1px + 紫渐变 2px 外描边，可加 6–10px 沿线光点单向流动（速度 1.2–2s/屏，仅 1–2 条，禁用全图霓虹）。
  • 主节点放大 1.2×，中央枢纽用紫渐变玻璃环。

4.3.8 地图（若行业需要）

  • 底图使用浅暖色填充 + 玻璃感；区域描边 rgba(58,52,84,0.15)。
  • 热点：紫色光晕点（径向渐变，无硬圈）+ 白芯；告警热点红色。
  • 禁止：暗黑底图、发光扫描线、全屏霓虹飞线。

4.3.9 事件流 / 时间线（告警、流水线日志）

  • 时间线：左侧状态点（成功绿/失败红/运行紫呼吸）+ caption 时间戳 + body 事件描述；行 hover 淡白玻璃底。
  • 最新事件置顶，虚拟滚动保持流畅。
  • 事件行右侧：关联资产玻璃 chip。

4.5 数据色序使用规则

  1. 单序列 → purple-500；双序列 → purple-500 + cyan-500；三序列 → purple + cyan + blue；更多按 [2.1.6](#ch-02) 顺序。
  2. 状态（好/中/坏）→ 严格用 success / warning / danger。
  3. 同一指标跨卡必须同色（如所有"攻击数"都紫、所有"流量"都蓝）。
  4. 语义最强的序列放最前（顺序 1 紫 始终给主角）。
  5. 禁止：默认 Excel 彩虹、相邻序列同明度导致难辨——必要时相邻两色用 500 与 300 明度错开。

07-交互动效与微交互规范

07 · 交互动效与微交互规范（Motion & Micro-interactions）

本章把动效定义为设计系统的正式维度，与颜色 / 玻璃材质同级管理。
动效总纪律：克制、有语义、像材质在呼吸——绝不炫技，绝不做广告式闪烁。
交互演示见 [preview/index.html](preview/index.html) 的「微交互」区，组件清单见 [03 · 组件规范](#ch-03)，图表动效见 [04 · 4.6](#ch-04)。

7.1 动效分级（Motion Hierarchy）

所有动效按「目的」分四级，从最常用到最克制：

M1 即时反馈   hover / active / focus / 按压 —— 触摸级，80–250ms
M2 状态过渡   开关 / 勾选 / 分段 / 页签 / 弹层 —— 240–400ms，可带 1 次柔和回弹
M3 数据与入场  数字滚动 / 图表绘制 / 面板浮现 / 切换路由 —— 400–900ms
M4 环境氛围   呼吸光 / 缓慢浮动 / 拓扑光点 —— ≥2.4s 循环，仅表达"实时"，≤5 处

规则：

  1. 反馈（M1）是唯一允许无条件存在的动效——交互没有反馈等于"失灵"。
  2. 环境氛围（M4）是唯一允许无限循环的动效，但全屏同时循环的元素 ≤5 个。
  3. 循环频率 < 0.5Hz（周期 <2s）会被视为"报警级"，只允许出现在真正需要报警的状态。
  4. 动效只表达状态，不表达装饰；说不出语义的动效直接删掉。

7.3 组件级微交互配方（Component Recipes）

每条配方 = 触发 → 变化 → 时长 / 曲线。可直接照抄 CSS。

7.3.1 按钮 Button（M1 + M2）

hover   → 浮起 4px + 主按钮紫辉光(glow-purple-soft) + 白色高光从左到右扫过(sheen 0.8s 一次)
active  → 按回平面 translateY(0) + scale(.97)，120ms 内完成 —— "有回弹的玻璃"
focus   → 外圈 4px 紫色柔光 ring，200ms 淡入
disabled→ 无任何动效
图标按钮 → hover 图标微上浮；带动画的箭头图标在 hover 时右移 2px
loading → 图标位换 18px spinner（顺时针 0.9s/圈），按钮禁止旋转整体
.btn{position:relative;overflow:hidden;transition:transform var(--lg-t-base) var(--lg-ease-out),
     box-shadow var(--lg-t-base) var(--lg-ease-out),background .3s ease}
.btn:hover{transform:translateY(-2px)}
.btn:active{transform:translateY(0) scale(.96);transition-duration:var(--lg-t-fast)}
.btn::after{content:"";position:absolute;inset:0;
  background:linear-gradient(105deg,transparent 40%,rgba(255,255,255,.45) 50%,transparent 60%);
  transform:translateX(-130%)}
.btn:hover::after{animation:sheen .7s var(--lg-ease-in-out) 1}
@keyframes sheen{to{transform:translateX(130%)}}

7.3.2 卡片 / 面板 Card（M1 + M3）

hover   → 浮起 6px + 阴影从 md 加深到 lg（只动 transform + box-shadow）
入场    → opacity 0→1 + Y 16px→0，800ms ease-out；多卡按 60–90ms 错峰
Hero 悬浮件 → 常驻缓慢浮动 ±6px / 7–9s ease-in-out 交替（仅 Hero 区 2–3 件）
禁止    → 卡片内容整体位移动画、翻转卡、弹簧进弹
.kpi,.glass-l2{transition:transform var(--lg-t-base) var(--lg-ease-out),

.kpi:hover{transform:translateY(-4px);box-shadow:var(--lg-glass-highlight),var(--lg-shadow-lg)}

7.3.3 开关 Switch（M2，唯一允许"活泼"的控件）

滑块    → left 0↔19px，300ms ease-spring（轻微过冲，像被拨过去的玻璃珠）
轨道色  → 灰↔紫渐变，250ms ease-out
打开态  → 外圈 3px 紫色柔光淡入 200ms
.switch .track{transition:background .25s ease,box-shadow .25s ease}
.switch .track::after{transition:left .3s var(--lg-ease-spring)}

7.3.4 复选框 / 单选框 Checkbox（M2）

勾选    → 内部紫渐变块 scale .4→1 + 200ms spring；外框白色淡出
取消    → 内部块 120ms 收缩淡出
.chk .box::after{transition:transform .22s var(--lg-ease-spring),opacity .18s ease}

7.3.5 分段控件 / 页签 Segmented & Tabs（M2）

分段    → 玻璃"滑块" 平移 + 变宽到目标项，280ms ease-out（禁止瞬移、禁止逐项缩放）
页签    → 底部紫渐变指示条 scaleX 0→1（当前项），300ms ease-out；切换时上一项收回
文字色  → 200ms 过渡到激活紫
.seg .thumb{transition:left .28s var(--lg-ease-out),width .28s var(--lg-ease-out)}
.tab::after{transform:scaleX(0);transform-origin:center;transition:transform .3s var(--lg-ease-out)}
.tab.on::after{transform:scaleX(1)}

7.3.6 输入框 Input（M1）

focus   → focus ring（4px 紫 15%）200ms 淡入；内阴影保持，无跳动
错误    → 边框转红 + 轻微左右抖动一次（±4px × 3，240ms）仅表单校验

7.3.7 气泡 / 浮层 Tooltip · Popover · Modal · Toast（M2）

Tooltip → opacity 0→1 + Y4px→0，180ms ease-out；跟随目标出现（M1 触发）
Popover → scale .96→1 + Y8px→0，240ms ease-out，transform-origin 指向触发点
Modal   → 遮罩淡入 250ms；面板 scale .98→1 + 下移 12px→0，320ms ease-out
Toast   → 顶部滑入 320ms → 驻留 2.4s → 淡出上滑 240ms；同类 Toast 只存在 1 条（堆叠会显得乱）

7.3.8 导航 Navigation（M1 + M2）

侧栏项  → hover 淡白玻璃底 150ms；选中态紫渐变 250ms 淡入（不瞬移）
徽标    → 数值变化时 scale 1.08→1 弹一下（220ms spring），仅变化瞬间
顶栏    → 页面下滑后 240ms 淡入并加玻璃模糊（吸顶时），回顶还原
抽屉/侧栏 → 320ms ease-out 滑入滑出

7.3.9 KPI 数字与图表（M3）

数字滚动 → 900ms ease-out，tabular-nums 防跳动；只滚主数值，单位不动
变化提示 → 数值上升：背景 1 次极淡绿色上扫(400ms)；下降：淡红；同屏只允许 1–2 个
图表绘制 → 折线用 pathLength=1 的 stroke-dashoffset 900ms 画出；面积填充 200ms 后淡入
柱状生长 → 700ms ease-out，多条按 60ms 错峰自下而上；环图 800ms 旋转填充
拓扑活动 → 白芯 + 紫/青光点单向流动（1.2–2s/段），全屏 ≤2 条（见 04）

7.3.10 状态点呼吸（M4，唯一无限循环）

7.5 性能与无障碍纪律

  1. 只动 transform 与 opacity；box-shadow 过渡少量可用；backdrop-filter 不做逐帧动画（重绘成本高）。
  2. will-change 只在动画开始瞬间加、结束即删；全屏同时 blur 节点 ≤6（见 [06 · 6.5](#ch-06)）。
  3. 闪光安全：任何动画频率 < 3Hz（周期 >330ms）；杜绝 >3Hz 的闪烁（癫痫安全）。
  4. 尊重系统设置：prefers-reduced-motion: reduce 时关闭 M3/M4 与一切位移类动效，仅保留 100ms 内不透明度反馈：
@media (prefers-reduced-motion:reduce){
  *,*::before,*::after{animation-duration:.01ms!important;animation-iteration-count:1!important;
    transition-duration:.01ms!important;scroll-behavior:auto!important}
}
  1. 动效不承载唯一信息：禁用态 / 危险状态必须同时有颜色 + 文字，不能只靠动画表达。
  2. 触屏：hover 效果需降级为 @media (hover:hover) 启用，否则移动端"粘 hover"。

交互状态通则

  1. hover 与 press 二选一呈现：桌面 hover、触屏 press（@media (hover:none)），同一组件不得同时依赖两者传达信息。
  2. focus 可见：键盘导航一律 :focus-visible 显式焦点环（玫瑰色 2px ring），不得隐藏到 outline:none。
  3. disabled 需给理由：禁用态用 caption 文案或 Tooltip 说明原因（"未到可预约时间"优于裸禁用）。
  4. loading 不换内容：只换图标位（细环 0.9s/圈），按钮文字保留（"保存中…"同长度避免跳动）。
  5. 错误态三通道：颜色（红）+ 文案 + 图标，任一通道可单独传义（医疗合规同 13.5）。
  6. 每次交互 ≤250ms 起反馈；需要等待的操作立即进 loading，禁止"点了没反应"。

7.9 通用可访问性（ARIA / 读屏 · A3 落地，2026-09）

  • 键盘操作：可交互元素须为原生可聚焦，或显式 tabindex="0"；方向选择类（radio / tabs / segmented）支持 ←/→/Home/End，并同步维护 aria-checked / aria-selected。
  • 读屏语义：图标装饰位 aria-hidden="true"；需独立传义的图标用 role="img" + aria-label；分组选择器容器给 role="radiogroup" / group 与可读 aria-label。
  • 状态双通道：颜色从不单独传义（15.2 六语义始终 + 文字/图标）；加载/进度类变化提示使用 role="status"。
  • 焦点管理：弹层打开时聚焦首个可交互元素，关闭后归还触发点；键盘走查静态断言见 scripts/a11y.py（已并入 CI）。

10.5 内容与图表适配

10.5.1 KPI 与卡片流

  • 核心 KPI 卡可满宽：左"指标名 + caption"，右大数字（--lg-m-num-xl）与 delta。
  • 双指标对排使用 1/2 宽卡；禁止 3+ 指标横向挤一屏。
  • sparkline 缩至 96–140 宽；图表卡不横向滚动堆叠。

10.5.2 图表降级规则（对 04 的移动版）

  1. 单图单卡：一屏最多 1 张主图 + 数字摘要；不做并排联动。
  2. 序列降级：折线 ≤2 条、柱 ≤2 组、环形 ≤5 段（其余并"其他"）；删次要网格。
  3. 数据色序不变（02.1.6 紫→青→蓝…），保证 PC/移动同一语义同色。
  4. 数值聚焦：卡头放关键读数大数字 + caption，图作趋势佐证；tap 图内点 → 该点玻璃气泡显示精确值（长按才触发，避免干扰滑动）。
  5. 面积图 > 折线（易读）；禁交互依赖 hover 的图（无 hover）。
  6. 移动端加载：图表用 Skeleton 占位，禁止整卡旋转。

10.5.3 表格 → 卡片列表

行卡片：头像/状态点(左) + 主信息两行(中) + 右侧关键值/箭头(右)
状态行可直接按状态排序过滤；需要对比的窄表 → 横滑（首列冻结，滚动条隐藏）

11.2 新增组件细则（Mobile Specs）

通用：玻璃档位 L2/L3、圆角 --lg-m-radius-*、press 反馈 scale .97、热区 ≥44；默认图标 22（lg-icon-*）。

11.2.1 SearchBar 搜索栏

  • 形态：整行玻璃胶囊（L3，高 40–44，圆角 18）：左侧 lg-icon-search（三级色）+ 输入 + 右侧「搜索」文字键（或相机/扫码预留）。
  • 进入搜索页模式：点击整条输入聚焦，下方实时建议列表（玻璃行），取消键出现。
  • 交互：聚焦时胶囊提亮 + 紫 focus ring（07）；内容清空按钮出现（lg-icon-close）。

11.2.2 Segmented 分段（可横滑）

  • 整行横滑玻璃条：当前段紫渐变玻璃滑块平移（07 状态过渡），左对齐滚动；段之间留 4px。
  • 每段内边距 16，高 36–40，文字 14；段数多时可两行分段（≤6）。
  • 用于：日/周/月、全部/在线/告警、视图切换。

11.2.3 IndexBar 索引栏

  • 右侧纵向字母胶囊列（A–Z + #），当前索引放大为 40px 悬浮玻璃徽标；中央出现大字当前字母（玻璃圆 56）。
  • 点击字母：列表平滑滚到该分组，首行分组标题 sticky 玻璃小条。
  • 使用场景：资产清单、通讯录、合规文档库。

11.2.4 Cell 单元行（分组列表）

  • 分组：组标题（caption 三级色）+ 组内白玻璃卡列表，行高 52–56；行 = 左图标/头像 + 标题(+副标题) + 右值/lg-icon-chevron-right。
  • 点击行：press 高亮 + 右侧箭头 200ms 右移 2px 再归位（07）；可点行禁止用 hover 样式。
  • 危险操作行文字 danger 色 600；末行做圆角收尾（上圆 18/下圆 18，整体一组一块玻璃）。

11.2.5 SwipeAction 滑动操作

  • 行左滑露出操作区：玻璃底行 + 右侧操作按钮组（圆角 12，白玻璃底或 danger 底红字），最大露出 3 个操作。
  • 手势：左滑 300ms ease-out 贴靠；再滑或点空白收起；滑动中行内容 1:1 位移，禁止弹簧错位。
  • 操作按钮 ≥64 宽；删除类 danger；确认删除走二次确认（ActionSheet）。

11.2.6 Collapse 折叠面板

  • 玻璃卡 + 标题行（44 热区，左侧可加状态点），展开时下方内容淡入 + 高度过渡 300ms（07 M3，高度用 grid-template-rows 技巧避免布局抖动）。
  • 箭头 lg-icon-chevron-down 旋转 180°（220ms）；一屏同时展开 ≤3 组。
  • 用途：筛选器、策略详情、多指标详情。

11.2.7 Swiper 轮播

  • 玻璃圆角页 + 左右滑动（原生滚动 + scroll-snap）；底部指示点 = 3px 白玻璃胶囊，当前点扩展为紫渐变 12px（宽度过渡 220ms）。
  • 自动轮播仅用于运营位且需暂停（用户触碰即停）；内容卡可带主标题文字（勿轮播文字密集型内容）。

11.2.8 NoticeBar 公告条

  • 单行公告：玻璃胶囊（L3 淡版）内 lg-icon-bell + 文字 12px + 关闭；文字超宽可循环滚动（24px/s，暂停于用户触碰），或使用 ActionSheet 展开全文。
  • 仅 1 条在屏（多条排队）；危险级公告用 danger 语义色图标。

11.2.9 ImageViewer 图片预览

  • 全屏玻璃浮层（遮罩 0.22 白 + blur 40）：图片居中可缩放/旋转（双指）；顶部右上角关闭（44 圆钮）。
  • 背景缩放背景同图增强沉浸；底部可选操作行（分享/保存，ActionSheet 风格）。
  • 性能：原图懒加载 + 缩略图预载。

11.2.10 Result 结果页

  • 全屏结果态（或卡片内）：图标 56–64（成功 lg-icon-success 绿 / 失败 lg-icon-error 红 / 空 lg-icon-search）+ 主文案 18/600 + 说明 14 caption + 1–2 个按钮（主行动 + Ghost）。
  • 入场 500ms 淡入 + 图标 spring 弹出一次（07）；页面内嵌于表单提交场景。

11.2.11 Stepper 步进器

  • 玻璃胶囊：左侧 − 钮 40×40 圆角 12、中间数值 16 600（tabular-nums）、右侧 + 钮；长按连续步进（200ms 首动 60ms 连发）。
  • 禁用到边界时按钮 opacity .4；用于配额、副本数、阈值。
  • 键盘场景（精确输入）可切换为输入框形态（Cell 内）。

11.2.12 Rate 评分

  • 玻璃星形（lg-icon-star 22px，选中 fill 紫/金渐变禁用→ 灰 outline）；点选 spring 弹动 200ms 一次；支持半星（clip-path）。
  • 有评分文案联动（如「优秀」）；提交类评分才用，展示类用静态星。

11.2.13 Upload（拍照/相册）

  • 9 宫格缩略卡（86×86 圆角 16，白玻璃底）：点击放大预览（11.2.9）；右下角删除角标（danger 圆点 18）。
  • 末尾「+」玻璃卡（dashed 描边）：点击弹 ActionSheet「拍照 / 相册 / 取消」；上传中缩略卡盖半透明 + 右上玻璃小环（细环 0.9s/圈）。
  • 失败卡红边 + 重试按钮；单张上限 9、类型/大小在 ActionSheet 文案说明。

11.2.14 OTP 验证码

  • 玻璃格 44×52 圆角 14，间距 8，focus 格紫渐变描边 + 光标；自动跳下一格，粘贴整串自动分发。
  • 倒计时 60s 重发（caption 紫字可点，计时中三级色不可点）；数字 tabular-nums。

11.2.15 Dialog（移动版）

  • 居中玻璃卡（宽 ≤ 屏宽-64，圆角 24）：图标/标题 17 600 + 内容 14 + 按钮区。
  • 按钮布局：单按钮全宽，双按钮竖排优先（确认在下，取消在上 Ghost），横排仅 2 短词可用。
  • 危险确认：确认钮 danger 玻璃渐变；遮罩 0.18 白 + blur 8；入场 scale .96→1 260ms。
  • 移动端规则：一个 Dialog 一个焦点；复用同一实例防多弹。

  • 刘海/底部指示条自动适配：env(safe-area-inset-*) 封装为组件；
  • 用法：导航/主行动/TabBar 之上加 SafeArea；内容卡片不重复加（10.2 段已给 CSS）。

11.6.8 Sticky 吸顶

  • 吸顶对象：搜索栏（列表页）、筛选 chips、日期表头、NavBar 之下二级工具条；
  • 玻璃底（blur ≤24）+ 滚动过 80px 后淡入阴影（07 M1）；不与系统下拉刷新冲突（预留给 PullToRefresh 阈值）。

11.6.9 ErrorBlock 异常块（业务空/错态）

  • 复用 Result/Empty 玻璃样式：图标 56（网络/无权限/服务器）+ 主文案 + 说明 + 重试按钮；
  • 场景化：列表加载失败（重试/刷新）、无网络（检查后重试）、无权限（联系管理员）。

11.6.10 NumberKeyboard 数字键盘（新增）

  • 玻璃键盘底（L4 淡版）：3×4 数字 + 删除 + 完成；输入回显玻璃胶囊；

11.6.11 Footer 底部（新增）

11.6.12 Dropdown 筛选下拉（移动）

  • 确认行固定在面板底（主行动全宽）+ Mask 点击取消；展开时页面滚动锁。

13.5 医疗合规与视觉纪律

  1. 医学数值区域字号 ≥ 13、tabular-nums；单位与标准来源（如「WHO 0–5 岁标准」）以小字标注。

  3. 异常不单独靠颜色传达（颜色 + 文案 + 徽章三通道，07 无障碍纪律）。
  4. 大面积彩色背景仍禁止；粉色只做品牌与宝宝数据，医疗版面保持浅奶底 + 克制的彩色。
