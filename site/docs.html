完整 Do/Don't 见 03 · 3.11；此处按组件分类给出用法要点。

分类正确用法禁止

通用 · Iconlg-icon-*；同屏同描边；行内 -2px、按钮内 15–18Emoji / 字体图标混排 / <12px

数据输入 · Form/Input一屏一任务；错误三通道；提交唯一 Primary键盘遮挡 / 只变红提示

导航 · Nav/Tab分组 ≤6、唯一高亮；桌面悬停、移动点按hover-only（触屏粘滞）/ 深导航

③ 国际化 · 最小示例

词库以 15 章为唯一语言源；应用侧做键值字典即可扩展。示例模式：t('待随访', 'zh'|'en')

// goodmom-ui/src/i18n.ts（最小实现）
export const DICT = {
  '待随访': { zh: '待随访', en: 'Pending follow-up' },
  '已建档': { zh: '已建档', en: 'Registered' },
  '提交':   { zh: '提交',   en: 'Submit' },
} as const;
export function t(key: keyof typeof DICT, lang: 'zh'|'en' = 'zh') {
  return DICT[key][lang];
}

落地：接入 i18next / react-i18next 后，把 DICT 作为资源合并即可；界面字串统一来自 15 词库。

③ 暗黑模式 · 最小示例（点击体验）

机制：顶层 `data-theme="dark"` 覆盖 Token → 页面即换肤。设计口径见 12.3.2「冷静模式/双模式」。

<html data-theme="dark"> …
:root / [data-theme="dark"]{ --bg / --t / --card-bg … 覆盖 }

本页即演示：变量化的背景/文字/卡片在 data-theme 下整体换肤；生产端把 gm-arco-ui 的 theme.css 变量同样数据化即可全库暗色。
